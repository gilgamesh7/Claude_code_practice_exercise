# Claude_code_practice_exercise
Learn how to use Claude Code CLI to build a complete web application by describing requirements in natural language rather than writing code from scratch.

# Install
- Claude Code : 
    - brew install --cask claude-code
    - echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
    - source ~/.zshrc
- Node :
    - brew install node
    - In the project folder: npm install
# Run
- Local : 
    - brew install node
    - npm run dev
    - open http://localhost:5173
